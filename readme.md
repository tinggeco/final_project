# Classroom Usage & Power Analysis Output Files

本資料夾包含各教學館的課堂使用量、用電功率，以及扣除基礎功率後的分析結果。  
目前處理的教學館包含：

- 共同教學館
- 博雅教學館
- 普通教學館
- 新生教學館

---

## Output Files

| 檔案名稱格式 | 說明 |
|---|---|
| `{教學館}_classroom_usage_day.csv` | 統計該教學館「年度學期 × 星期 × 小時」的課堂使用資料。 |
| `{教學館}_classroom_usage_week.csv` | 統計該教學館依「年度學期 × 星期」彙整後的課堂數。 |
| `{教學館}_power_day.csv` | 統計該教學館依「年度學期 × 星期 × 小時」彙整後的平均功率。 |
| `{教學館}_power_week.csv` | 統計該教學館依「年度學期 × 星期」加總的功率結果。 |
| `{教學館}_扣除星期六基礎功率_0700_1800.csv` | 保留 07:00–18:00 每小時資料，並計算「平均功率 − 同學期同小時星期六基礎功率」。 |
| `{教學館}_功率除以課堂數.csv` | 將扣除基礎功率後的功率加總，再除以課堂數，得到每堂課平均功率。 |

---


## Processing Logic

### 1. 課堂使用量統計

`classroom_usage_day.csv` 與 `classroom_usage_week.csv` 用於整理各教學館在不同學期與星期的課堂使用情形。

### 2. 每小時平均功率

`power_day.csv` 以「年度學期、星期、小時」為單位，計算每小時平均功率。

### 3. 星期六基礎功率扣除

以星期六作為基礎功率 baseline，對星期一至星期五同學期、同小時的平均功率進行扣除：

```text
扣除基礎後功率_kW = 平日平均功率_kW - 星期六基礎功率_kW
```

若分析時不希望出現負值，可在程式中使用 `.clip(lower=0)` 將負值設為 0。

### 4. 功率除以課堂數

先將 07:00–18:00 的「扣除基礎後功率」依照年度學期與星期加總，再除以對應的課堂數：

```text
功率_每堂課_kW = 功率_kW / 課堂數
```

此結果可用於比較不同教學館、不同星期或不同學期中，每堂課所對應的平均用電功率。
